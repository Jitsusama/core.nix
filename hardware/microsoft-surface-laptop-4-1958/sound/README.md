# The Surface Laptop 4's Sound

What the laptop's microphones need beyond core's PipeWire module.
[docs/hardware.md][hardware] says how their level was measured.

| File              | Holds                                                      |
| ----------------- | ---------------------------------------------------------- |
| `microphones.nix` | the profile set that gives PipeWire the microphones' path  |
| `paths/`          | that path, which keeps their gain at a level calls can use |
