# Worked Examples

Each loved site taken apart, under a made-up name, for the step of the
web-design skill that calls for one:

- `proposal.md`: the Ledger, a one-page proposal, a page to read.
- `tour.md`: the Crossing, a guided tour of a new design.
- `site-of-pages.md`: the Spring, a site of several pages about one thing.
- `tracker.md`: Slack Water, an issue tracker, an interface to work in.
- `what-went-wrong.md`: the pages turned down on 15 November, and why.
