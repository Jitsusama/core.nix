Keys

j k
Step to the next or the last cell; the one you're on opens beside the list
g G
Go to the first or the last cell
-, h
Step up to the cell that started the one you're on
/
Find a cell by its name, its quest, its purpose or a document's title; Return keeps the find, Esc ends it
Return
Open the cell you're on in the map
y
Copy the command that says the cell's forage in a terminal
? F1
This list, and again to close it; Esc closes it too
