# The Switch's Status Pages

An 8-port TP-Link Easy Smart switch's four status pages, as it answered
them on 2026-11-14 once signed in, one file per page and byte for byte
apart from its name, hardware address and addresses. `src/sources/switch.rs`
parses them and the switch's reader is tested against them; `../README.md`
says how they were taken and what was replaced.
