# The Hour's Measures

One module for each measure the hour reads against its target, such as
`ruled.rs`, which counts claims of Joel's rule with no word of when he said
it, and a few that several measures share, such as `owner.rs`. `measures.rs`,
one folder up, declares them and holds the measures too small for a file.

Many entries because a module with parts of its own is both a file and a
folder of one name, so the eleven that have grown parts take twenty-two
entries, and each of the rest is one measure or one shared part: grouping
them by kind would put a measure's file away from the folder holding its
parts. A measure that grows parts of its own takes a folder.
