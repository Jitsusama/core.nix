# A Busy Week

The stand-in commands-agree runs spend-watch's views against, set in a
scratch folder as XDG's homes: three pi sessions over the last week, two
of them serving a quest, one rebuilding its context after a pause. Each
view imports them first, as a person would, then reads the report. Times
are written as `@ISO-N@` and paths as `@HERE@`, set as the check runs.

- `config/`: spend-watch's settings, pointing every path inside here.
- `sessions/`: pi's session logs, as pi writes them.
- `quests/`: the harness's quest store, a README each, one with a title
  long enough to need cutting in a narrow terminal.
