# A Full Disk

What an account's folders hold while its disk is nearly full, for
commands-agree to set disk-guard's status and bare run at each width from.
Each folder is one of the account's XDG folders, put in place as the one
its variable names, and each `.in` file is written without its suffix,
its `@NOW-N@` times set to N seconds before the view runs.

- `runtime/`: `$XDG_RUNTIME_DIR`, where the user guard writes its status.
