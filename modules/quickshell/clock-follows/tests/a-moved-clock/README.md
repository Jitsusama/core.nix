# A Moved Clock

The stand-in commands-agree runs clock-follows' bare run against, set in
a scratch folder as XDG's homes: a clock moved three hours ago from
Toronto's zone to Edmonton's, in a made-up place, and a zone put back
from and held. The move's time is written as `@NOW-N@`, set as the check
runs.

- `state/`: the account's state, as the unit keeps it in
  `%S/clock-follows`.
