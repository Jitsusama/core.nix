# The Shell's Stand-Ins

What the shell's checks stand in for, so a case meets what it reads without a
machine: a daemon's sources, niri's screens, the notices and sessions Now holds,
the state pi's sessions and the machine's node leave, a session log for
spend-watch to import, and what each screenshot says for the search by words.
Each script opens saying what it stands in for, and the checks that take them
are in `../../checks/`, in the file of the place each serves.
