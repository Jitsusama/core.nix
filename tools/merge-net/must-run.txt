# The changes that run their VM tests before they merge, rather than after
# on the net: those that can leave a machine unable to boot, unlock, sign
# in or build, where a revert after the fact comes too late for a machine
# that switched to it. Each line is an area, the paths that are it, and
# after `=>` the VM tests it runs. A `*` stands for anything, a `/` too.
# Only those whose derivation moved from main run, since the rest would
# give main's result. A `there` among the tests marks what runs VM tests,
# whose change moves none of them: it asks for one VM test sent through
# the change itself, end to end.
